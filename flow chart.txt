Extension:
==========
   The proposed model is a novel machine learning approach for accurately predicting and classifying job failures in modern cloud data centers. By combining multiple classifiers through a fine-tuned voting mechanism and leveraging Random Forest for failure type identification, the ensemble voting classifier (MMPF) achieves outstanding accuracy of 99.83% in failure detection and 99.97% in failure classification using the Google Cluster 2019 dataset.

    As an extension, we implemented an additional ensemble model using a Stacking Classifier, comprising Random Forest (RF), K-Nearest Neighbors (KNN), and Multilayer Perceptron (MLP) as base estimators, with Logistic Regression as the meta-estimator. This stacked model achieved an impressive 100% accuracy in predicting job failures. All existing and proposed models were built and evaluated for performance comparison.

    To enhance interpretability, we employed Explainable AI (XAI) techniques such as LIME and SHAP to analyze and visualize the importance of feature values contributing to the predictions. Furthermore, a Flask-based user interface was developed, allowing users to input data and obtain predictions using the trained models on the dataset.
